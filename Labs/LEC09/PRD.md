# 소닉 애니메이션 뷰어 개발 문서

## 1. 개발 목표

Python과 pico2d를 이용해 소닉 스프라이트 시트의 모든 동작을 자동으로 보여주는 프로그램을 만든다. 각 동작을 구분해서 확인할 수 있도록 충분히 확대하고, 일정한 순서로 반복 재생한다.

| 항목        | 내용                                    |
| ----------- | --------------------------------------- |
| 작업 폴더   | `Labs/LEC09`                          |
| 소스 파일   | `sonic_animation_viewer.py` 단일 파일 |
| 이미지      | 같은 폴더의`sonic-sprite.png`         |
| 작업 브랜치 | 현재 생성한`lec09-animation-viewer`   |
| 기본 실행   | `python sonic_animation_viewer.py`    |

`PRE_PRD.md`의 `sonit_sprite.png`는 실제 파일명으로 바로잡는다. 브랜치도 이미 생성한 이름을 기준으로 진행한다.

## 2. 스프라이트 분석과 데이터

- 이미지의 동작 묶음과 프레임 순서를 먼저 확인한다. 서로 다른 동작이 같은 줄에 있을 수 있으므로 줄 전체를 하나의 동작으로 가정하지 않는다.
- 시트 안의 소닉 동작을 빠짐없이 목록으로 정리한다. 제목, 제작자 표기, 다른 캐릭터는 재생 영역에서 제외한다.
- 프레임 크기와 간격이 일정하지 않으므로 각 프레임의 `x, y, w, h`를 직접 기록한다.
- 동작마다 이름, 프레임 목록, 재생 간격을 둔다. 프레임 수는 목록 길이로 계산한다.
- 동작 이름과 정확한 프레임 수는 이미지 분석 단계에서 확정한다. 한 장짜리 자세도 별도 동작으로 포함한다.
- 프레임 정보는 Python 파일 안의 리스트와 딕셔너리로 관리한다.

## 3. 화면과 재생 규칙

### 화면 표시

- 기본 창 크기는 1200×800으로 하고, 캐릭터를 화면 중앙에 배치한다.
- 기본 자세의 높이가 화면 높이의 절반 정도가 되도록 공통 확대 배율을 정한다.
- 가로·세로 비율을 유지하고, 가장 큰 동작도 창 밖으로 잘리지 않도록 확인한다.
- 프레임 크기가 바뀌어도 캐릭터가 불필요하게 흔들리지 않도록 발 위치나 몸통 기준점을 맞춘다. 점프 등 원래 동작의 이동은 유지한다.

### 재생 순서

1. 첫 동작의 첫 프레임부터 마지막 프레임까지 재생하면 1회로 센다.
2. 같은 동작을 총 5회 재생한다. 한 장짜리 동작도 설정된 간격으로 5회 표시한다.
3. 마지막 프레임을 표시한 상태로 1초 정지한다.
4. 다음 동작으로 넘어가고, 마지막 동작이 끝나면 첫 동작으로 돌아간다.

프레임 간격은 우선 0.1초로 시작하고 실제 동작을 보며 조절한다. 필요한 경우 동작별 간격을 다르게 설정한다. 재생 중과 1초 정지 중 모두 ESC 키와 창 닫기에 즉시 반응하도록 한다.

## 4. 코드 구성

| 구성             | 역할                                               |
| ---------------- | -------------------------------------------------- |
| 설정값           | 창 크기, 확대 배율, 반복 횟수 5, 정지 시간 1초     |
| 동작 목록        | 이름, 프레임 좌표와 크기, 기준점 보정값, 재생 간격 |
| `draw_frame()` | 화면을 지우고 해당 프레임을 잘라 확대 표시         |
| `wait()`       | 일정 시간 기다리는 동안 종료 입력 확인             |
| `play()`       | 한 동작을 5회 재생하고 1초 정지                    |
| `main()`       | 창·이미지 준비, 전체 동작 반복, 종료 시 창 정리   |

- 이미지 경로는 `__file__`이 있는 폴더 기준으로 처리해 다른 폴더에서 실행해도 이미지를 찾는다.
- 프레임 좌표를 이미지 왼쪽 위 기준으로 기록하고, pico2d에서 자를 때 `이미지 높이 - y - h`로 세로 좌표를 변환한다.
- 이미지가 없으면 필요한 파일명을 알리는 오류를 표시하고 종료한다.
- 함수와 변수는 쉬운 영어 이름을 쓰고, 좌표 변환과 반복 처리에는 짧은 한글 주석을 단다.

## 5. 단계별 개발과 커밋

먼저 첫 동작이 실행되는 최소 버전을 만들고 나머지 기능을 차례로 붙인다. 모든 작업은 `lec09-animation-viewer` 브랜치에서 진행하며, 아래 20단계를 각각 실제 변경 내용이 있는 커밋으로 남긴다.

| 단계 | 작업 내용 | 한글 커밋 메시지 예시 |
|---|---|---|
| 1 | 시트의 소닉 동작 목록과 프레임 구분 기준을 문서에 기록 | `소닉 동작 목록과 개발 순서 정리하기` |
| 2 | 단일 Python 파일에 1200×800 창과 기본 실행·종료 구조 작성 | `소닉 뷰어 실행 창 만들기` |
| 3 | 소스 파일 위치를 기준으로 스프라이트 이미지 로딩 | `실행 위치와 관계없이 소닉 이미지 불러오기` |
| 4 | 첫 프레임의 영역을 기록하고 세로 좌표를 변환해 중앙에 표시 | `소닉 첫 프레임 잘라서 표시하기` |
| 5 | 첫 동작의 프레임을 0.1초 간격으로 순서대로 재생 | `소닉 첫 동작 연속 재생하기` |
| 6 | 동작별 프레임 목록과 `draw_frame()`을 사용해 서로 다른 크기·개수 지원 | `크기와 개수가 다른 프레임 처리하기` |
| 7 | 분석한 이동 계열 동작의 좌표와 재생 순서 추가 | `소닉 이동 동작 추가하기` |
| 8 | 분석한 회전 계열 동작의 좌표와 재생 순서 추가 | `소닉 회전 동작 추가하기` |
| 9 | 나머지 여러 프레임 동작을 추가하고 목록과 대조 | `소닉의 남은 연속 동작 추가하기` |
| 10 | 한 장짜리 자세를 별도 동작으로 등록하고 표시 시간 적용 | `한 프레임으로 된 소닉 자세 추가하기` |
| 11 | `play()`에서 첫 프레임부터 끝까지를 1회로 세어 5회 반복 | `각 동작을 다섯 번 반복하기` |
| 12 | 5회 재생 직후 마지막 프레임을 유지하며 1초 정지 | `동작이 끝나면 마지막 자세로 일 초 쉬기` |
| 13 | 정지 후 다음 동작으로 넘어가고 반복 횟수 초기화 | `다음 소닉 동작으로 순서대로 넘어가기` |
| 14 | 마지막 동작 이후 첫 동작으로 돌아가는 전체 반복 추가 | `모든 소닉 동작 무한 반복하기` |
| 15 | 공통 확대 배율을 적용하고 가장 큰 프레임의 화면 잘림 확인 | `소닉을 화면에 크게 확대하기` |
| 16 | 프레임별 기준점 보정값을 추가해 의도하지 않은 위치 흔들림 수정 | `동작이 바뀔 때 소닉 위치 맞추기` |
| 17 | `wait()`에서 대기 시간을 나누고 이벤트를 처리해 정지 중에도 창 닫기 지원 | `재생과 정지 중 창 닫기에 응답하기` |
| 18 | ESC 종료와 종료 경로의 캔버스 정리 처리 | `ESC 키로 소닉 뷰어 종료하기` |
| 19 | 실제 재생을 보며 동작별 프레임 간격 조절 | `소닉 동작별 재생 속도 조절하기` |
| 20 | 이미지 누락 시 파일명 안내 추가, 전체 실행 확인 결과를 문서에 기록 | `이미지 오류 안내와 최종 실행 확인 정리하기` |

7~10단계의 동작 묶음과 메시지는 1단계에서 분석한 실제 동작 이름에 맞춘다. 동작이 많으면 추가 커밋으로 나누어 20개 이상으로 진행한다. 각 단계에서 추가한 기능을 확인한 뒤 커밋하고, 메시지는 실제 변경 내용에 맞게 작성한다. 최종 파일을 한꺼번에 만든 뒤 커밋 수만 나누는 방식은 사용하지 않는다.

## 6. 완료 기준

- 분석한 소닉 동작 목록과 실제 재생되는 동작이 일치한다.
- 동작별 프레임 수가 달라도 처음부터 끝까지 정확히 재생된다.
- 각 동작이 5회 반복되고, 마지막 프레임에서 약 1초 멈춘다.
- 전체 순서를 두 번 이상 확인해 마지막 동작에서 첫 동작으로 이어지는지 검증한다.
- 확대 후에도 캐릭터가 잘리지 않고, 재생 속도와 기준점이 자연스럽다.
- 재생·정지 중 ESC와 창 닫기로 정상 종료되며, 다른 작업 폴더에서도 실행된다.
- 작업 브랜치에 변경 내용을 설명하는 커밋이 20개 이상 남아 있다.
